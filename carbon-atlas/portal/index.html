What does this work cost in carbon, and what does a move save?

The calculation multiplies the energy of each hour by the measured intensity of that hour. It compares three placements: stay in the current region, move the whole run to the best region, or follow the cleanest region hour by hour. The figure is a difference between average intensities. It is not a measured reduction.

What two publishers of one country measured

One hourly mean from each source, over every hour that both of them report. Source A is the first source id in alphabetical order, so the sign of the gap stays the same between runs. The gap is the mean of A less the mean of B. A share of a gap needs its denominator, and this table divides by the larger mean of the pair.

How the analysis computes these numbers

Which hour did each source call the cleanest?

A day counts only when both sources cover it with 24 hours. The test compares the hour of the lowest value of each source. Within one hour counts the days of the same hour too.

What each country needs for a discrepancy number

A discrepancy is the difference between two independent sources for one country and one hour. It needs two sources in the store. This table gives the state of each country: the sources that the store holds, and the sources in the register that can serve it next.

What this tab does not give yet the next step, not a result

The panels above measure one pair over all the hours that it shares. They give no row for each country and hour. The next step keeps that shape. It gives the spread of each hour, the widest pair of that hour, and the size of the spread against the mean. The store keeps each source separately, so no mixing is necessary and no value is lost.
